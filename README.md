## General

This repository contains information for the article: 

Cramer, M. T., Hearne, H. N., Lindeman, K. C., Bernus, J., Tuohy, E., Mac Donald, S., & Turingan, R. G. (2026). Marine and coastal protected areas in the Caribbean: Numbers, areal extent, distributions, no-take status, and management attributes. *Marine Policy 190*, 107140. https://doi.org/10.1016/j.marpol.2026.107140

## Contents

This repository provides the R script used for data preparation, statistical analyses, and figure generation, along with documentation describing the data-processing workflow.

## Data availability and access restrictions

The published article states that data files and the ArcGIS project are available through this repository. Availability has since been revised following a review of Protected Planet’s redistribution terms. WDPA-based data tables, summary CSV files, and the ArcGIS project containing downloaded source layers are not distributed here.

Protected Planet’s current terms restrict redistribution of source spatial and attribute data without authorization from UNEP-WCMC. Readers should obtain source data directly from [Protected Planet](https://www.protectedplanet.net/) and consult its [Terms and Conditions](https://www.protectedplanet.net/en/legal) for permitted use, attribution, and redistribution requirements.

To reproduce the study, use the WDPA release identified in the manuscript and follow the accompanying processing documentation and R script. The latest database release may differ from the version analyzed; access to the historical release may require contacting Protected Planet/UNEP-WCMC.
